# WB + Ozon Google Sheets / Apps Script

Новая самостоятельная версия системы управления магазинами Wildberries и Ozon.

## Принципы проекта
- Не зависит от `bmaks98/api-wb` и действующей таблицы.
- Не содержит токенов, ID таблиц и данных магазинов.
- Поддерживает WB, Ozon или оба маркетплейса.
- Отправка цен, остатков и управление акциями по умолчанию выключены.
- Один физический склад — источник фактического остатка.
- Создание карточек — с листа `Новые карточки`, фото хранятся прямо в ячейках.

## Текущий этап — dev3
Уже реализованы:
- установщик структуры из 16 листов;
- верхнее меню и лист `Начало работы`;
- настройки и безопасное хранение API-ключей в Script Properties;
- проверка подключений WB и Ozon;
- регламенты, журнал и уведомления по email/в таблице;
- защитные переключатели для цен, остатков и акций;
- импорт каталогов WB и Ozon;
- единый склад;
- автоматическое сопоставление товаров: артикул → штрихкод → название;
- сохранение ручных подтверждений сопоставления;
- выбор управляемого FBS-склада WB/Ozon по понятному названию;
- немедленное списание фактического остатка при новом заказе WB/Ozon;
- возврат количества при отмене до отправки;
- защита от повторного списания/возврата через `Журнал заказов`;
- отправка фактических остатков на WB и Ozon после включения защитного разрешения.

При первом импорте `Фактический остаток` остаётся пустым: система не пытается угадать реальное количество товара.

Если у маркетплейса несколько FBS-складов, в v1 выбирается один управляемый склад. Если склад один, он выбирается автоматически.

Карточки WB с несколькими размерами/вариантами не получают случайный `chrtId`: такие позиции пропускаются при отправке остатков и выводится предупреждение до отдельной поддержки вариантов.

Пока оставлены безопасными заглушками: цены, акции, дашборд, прогноз закупок, поставщики и создание карточек.

## Установка
1. Создайте пустую Google-таблицу.
2. Откройте **Расширения → Apps Script**.
3. Загрузите файлы из папки `src` (удобнее через clasp).
4. Запустите `installProject()` один раз и выдайте разрешения.
5. Вернитесь в таблицу и обновите страницу.
6. На листе `Начало работы` пройдите шаги по порядку.
7. На листе `Настройки` вставьте API-данные и выполните **Настройки → Сохранить API-ключи**.
8. Проверьте подключения.
9. Выполните **Настройки → Обновить список складов** и выберите склад, если их несколько.
10. Импортируйте каталог и проверьте сопоставление.
11. Заполните фактические остатки.
12. Только после проверки включите защитное разрешение на отправку остатков и нужные регламенты.

## Безопасность API-ключей
API-ключи вводятся на листе `Настройки`, затем командой сохраняются в Script Properties. После сохранения значения в ячейках маскируются. В репозитории ключи не хранятся.

## Репозиторий
Этот проект является отдельной версией. Исходный `bmaks98/api-wb` не изменять.
